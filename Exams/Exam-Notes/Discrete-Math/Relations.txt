Binary Relation on a Set:
    
    - A binary relation on a set A is a subset of A x A or a relation from set A onto itself

      if A = {1, 2, 3, 4} then the list of ordered pairs in set R if R = {(a, b) | a / b}

      R = {(1, 1), (1, 2), (1, 3), (1, 4), (2, 2), (2, 4), (3, 3), {4, 4}}

Reflexive Relations:

    - A relation R is Reflexive iff (a, a) ∈ R for every a ∈ A

      A = {1, 2, 3, 4}

      R = {(1, 1), (2, 2), (3, 3), (4,4)}

      in easy words a relation set must contain all the possible self loops to be reflexive

Symmetric Relations:

    - A relation R is Symmetric iff (b, a) ∈ R whenever (a, b) ∈ R

      A = {1, 2, 3, 4}

      R = {(1, 1), (1, 3), (2, 4), (3, 1), (4, 2)}

      in easy words the set R must contain (b, a) for every (a, b)

AntiSymmetric Relations:

    - A relation R on a set A is antisymmetric if ∀ (a, b) ∈ R and (b, a) ∈ R then a = b

      A = {1, 2, 3, 4}

      R = {(1, 2), (2, 2), (2, 3), (3, 4), (4, 1)}

      in easy words if R contains (a, b) and (b, a) then a must be equal to b

Trasitive Relations:

    - A relation R in a set A is trasitive if whenever (a, b) ∈ R and (b, c) ∈ R, then a = c

      A = {1, 2, 3, 4}

      R = {(1, 1), (1, 2), (1, 3), (2, 3)}

      in easy words if a = b and b = c then a = c i.e a, b, c must be an element in set

Irreflexive Relations:

    - R is irreflexive iff for all a ∈ A (a, a) ∉ R

      A = {1, 2, 3, 4}

      R = {(1, 3), (1, 4), (2, 3), (2, 4), (3, 1), (3, 4)}

      in easy words R must not contain any self loops.

Asymmetric Relations:

    R is asymmetric iff for all (a, b) ∈ R then (a, b) ∉ R

    A = {1, 2, 3, 4}

    R = {(1, 2), (2, 3), (3, 4)}

    in easy words asymmetric = antisymmetric + irreflexive
